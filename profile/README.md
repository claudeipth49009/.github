<p>如果只允许问三个问题，就把 Claude 纯净住宅 IP 的候选缩到两三家，该问哪三个？过去两年帮几个小团队换过供应商，我发现纠结的点往往不是"哪家更强"，而是"我这种规模要不要独享""几个号共用一条线会不会出事""预算有限先砍哪一项"。这篇不排榜单，按养号周期里真正会撞上的五个问题依次拆，每个问题给判断标准和对应的配置形态，末尾附一份可以直接照着问供应商的话术。</p>

<h2>一、第一个问题：养号阶段到底需不需要独享出口</h2>
<p>独享解决的是可归因性。同一个出口只服务一个账号时，出现验证码、登录失败、订阅异常，你能确定变量是网络还是操作；共享出口出问题，你永远分不清是别人把地址用脏了，还是自己动作太快。这个差别在账号刚建立的前两周最值钱。</p>
<h3>新号前两周为什么更敏感</h3>
<p>新账号还没有稳定的登录地记录、没有历史对话、没有支付记录，平台侧可参考的信号很少，任何一点异常都会被放大成"需要额外确认"。这段时间最好让出口地址、浏览器环境、登录时段三样东西保持单调，别做迁移、别换国家、别一天登录五个不同设备。</p>
<h3>什么规模下共享池仍然够用</h3>
<p>只做临时查阅、不涉及订阅和长期登录的账号，共享池完全可以应付，成本也低一个量级。判断线可以简单一点：这个号如果丢了你会不会心疼，会心疼就上独享；只是随手用用，共享池足够，别为心理安慰付溢价。</p>

<h2>二、第二个问题：多账号的出口按什么维度分组</h2>
<p>分组维度决定了后期扩容的难易。按运营人分组，交接时最省事；按项目分组，成本核算最清楚；按地区分组，账号资料一致性最好维护。三种都能用，但一个团队只能选一个主维度，混着来最后一定乱。</p>
<h3>按运营人分组：适合三人以内的小团队</h3>
<p>一个人一组出口，组内账号共享同一批地址。好处是责任清晰，谁的一组出问题找谁；坏处是人一走，出口和账号要整体移交，中途换人等于给这组账号换了一次登录环境。</p>
<h3>按项目分组：适合多业务并行</h3>
<p>不同业务线用不同出口段，账单可以按项目摊。这种分法在账号数超过二十个以后优势明显，因为你能算出每条业务线真实的网络成本，而不是年底一锅粥。代价是需要维护一张分组表，表过期了就等于没分。</p>

<h2>三、第三个问题：一条出口挂几个号才算边界</h2>
<p>行业里常见的说法是"一条线一个号"，实际执行时多数团队做不到，也没必要。更实用的口径是看三个变量：账号之间的业务是否相关、登录时段是否重叠、是否有支付行为。三者都重叠时，一条出口只挂一个号；都不重叠时挂两三个也能接受。</p>

<h3>并发不是唯一变量，行为重叠才是</h3>
<p>五个人在五个不同时段各用一个号，出口压力其实很小；一个人在同一分钟切换三个号，即使每条出口都干净，行为序列也很扎眼。安排使用时尽量错开时间，比多买几条线更省钱，也更容易长期维持。</p>
<h3>留一条备用出口的意义</h3>
<p>主出口抖动或需要替换时，有备用线可以先顶上，避免账号在故障期间被迫裸奔或者临时借别人的地址。备用线不必和主线同价位，能跑通登录即可，平时挂着低频探测，确认它还活着。</p>

<h2>四、第四个问题：换供应商时账号环境要不要重建</h2>
<p>换供应商本质上是换出口地址，账号本身不需要重建，但环境里依赖地址的部分要一起改。最容易漏的是浏览器里残留的地理位置授权、支付方式绑定的地区、以及各类客户端缓存的登录地信息。改一半比不改更麻烦，因为会出现自相矛盾的状态。</p>
<h3>可以保留与必须同步的两类项</h3>
<p>对话历史、项目设置、API 密钥属于账号资产，换出口不影响，保留即可。出口地址、时区、语言偏好、支付资料属于环境项，必须同批调整。判断标准很简单：这项信息会不会被平台读出来当成"你在哪里"的证据，会的话就一起动。</p>

<h2>五、第五个问题：预算有限时先保哪一项</h2>
<p>预算不够时最忌讳平均用力：便宜的线路配贵的地址，或者贵的线路配脏地址，两头都不讨好。正确的顺序是先保出口纯净度，再保地址稳定性，最后才谈带宽和节点数量。前两项决定账号能不能长期活着，后两项只影响手感。</p>
<h3>三项支出的排序理由</h3>
<p>纯净度是入场券，脏地址再快也没用；稳定性决定你要花多少时间在替换和重新验证上；带宽在 Claude 这类文本交互场景里需求很低，单账号日常对话占用的带宽几乎可以忽略，没必要为"大带宽"多付钱。</p>

<h2>常见问答</h2>
<h3>养号一定要一条线一个号吗？</h3>
<p>答：不是硬性要求，取决于重叠程度。业务不相关、登录时段错开、没有支付行为的账号，一条出口挂两三个在实践中能跑；但只要涉及订阅付款，建议单独一条，出问题时排查范围小很多。</p>
<h3>纯净住宅 IP 的价格区间大概多少？</h3>
<p>答：单条独享住宅地址月付大致在几十元到两百元之间，整段独享按段计费会到数百甚至上千元，具体随地区、带宽和是否原生段浮动，仅供参考。低于这个区间太多的，多半是共享池包装成独享。</p>
<h3>备用出口平时要不要一直开着？</h3>
<p>答：建议保持低频在线。完全不开的备用线，真到切换时经常发现配置过期、鉴权失效、地址已回收。挂一个每十分钟一次的探测请求，成本极低，能提前发现大部分问题。</p>
<h3>换出口后账号需要"养"多久才稳？</h3>
<p>答：观察期通常给到两到四周。这期间保持登录时段、设备、操作节奏不变，只看有没有额外验证。如果两周内反复出现验证，说明新出口质量不达标，别继续硬扛，尽早走替换流程。</p>
